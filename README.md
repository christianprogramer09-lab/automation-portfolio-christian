# Automation & AI Engineering Portfolio

## Project 1: KOSPRITE (Asset Processing Pipeline)
**Business Problem:** Manual processing of game assets caused development bottlenecks.
**Tools:** JavaScript, Node.js, File System API.
**Workflow:** 1. Assets are ingested through the automated pipeline.
2. Custom JS scripts perform automated cropping and compression.
3. Assets are routed to production directories.
**Outcome:** Reduced manual processing time by 40% (from ~5 hours/week to <3).

## Project 2: KOFIGHT (Backend Logic Automation)
**Business Problem:** Sychronizing complex game states between players in real-time.
**Tools:** Flutter, Supabase, PostgreSQL.
**Role:** Designed the backend architecture and algorithmic state management.
**Outcome:** Enabled simultaneous turn-based mechanics with millisecond latency.
